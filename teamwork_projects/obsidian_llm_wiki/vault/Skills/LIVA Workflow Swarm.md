# LIVA Workflow Swarm

Canonical instructions live in `.claude/skills/liva-workflow-swarm/SKILL.md` and the mirrored `.agents/skills/liva-workflow-swarm/SKILL.md`.

Use this skill to decompose objectives into Directed Acyclic Graphs (DAG), coordinate specialized subagent roles (Planner, Implementer, Reviewer, Challenger, Auditor), enforce voting consensus barriers, isolate faults via Dead Letter Queues (DLQ), and manage Human-in-the-Loop (HITL) approval checkpoints.
