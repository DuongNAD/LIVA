# LIVA Daily Planner

## Workflow

1. **Capture Agenda & Context**: Check current local time, calendar events, and active to-do lists from personal notes or task stores.
2. **Morning Briefing & Focus Blocks**:
   - Synthesize the top 3 high-impact priorities (MIT - Most Important Tasks) for the day.
   - Allocate realistic focus blocks (Pomodoro / Deep Work) avoiding overlapping commitments.
3. **Task Tracking & Urgency Triage**:
   - Prioritize newly incoming tasks using Urgency vs Importance triage.
   - Set reminder timers or alerts for critical deadlines.
4. **Evening Review & Daily Rollover**:
   - Log completed achievements and time spent.
   - Rollover unresolved items with updated priorities for the next morning.
5. **Persistence**:
   - Record daily logs and summaries into Obsidian Daily Notes using standardized timestamps.

## Stop Conditions

Stop and report when:
- Conflicting calendar appointments or time overbooking occurs without user resolution.
- Unspecified deadlines require clarification before setting high-priority alerts.
